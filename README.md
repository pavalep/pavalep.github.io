# Shalabham Software — Swatantryam

Static landing page for **Shalabham Software**, the team behind **Swatantryam** — a
family of free, open-source apps built on one rule: the model helps, but the data
stays with the user.

Live at <https://pavalep.github.io>

## What is here

| App | What it is | Code |
| --- | --- | --- |
| **Simba** | Open-source media player for Android (React Native + TypeScript), one typed adapter per free media catalogue | [pavalep/Simba-ReactNative](https://github.com/pavalep/Simba-ReactNative) |
| **Habitrak** | Offline-first habit and somatic-wellbeing coach (Flutter, Clean Architecture + BLoC, encrypted local vault) | [codernta/habitrak_app](https://github.com/codernta/habitrak_app) |

Both apps and every library they ship are MIT licensed. There is no account, no
subscription and no server dependency.

## Structure

```
index.html      the whole site
styles.css      the whole stylesheet
assets/         logo, app screenshots, founder photos
```

Plain HTML and CSS. No build step, no framework, no tracking.

## Editing

Open `index.html`, change the markup, push to `main`. GitHub Pages serves the
repository root, so the site updates within a minute of a push.
